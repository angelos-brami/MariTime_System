# R1 — Developing incident

1. Start the TTV clock at the first credible Tier A–C signal, or at a corroborated Tier E signal.
2. Create the event and isolated candidate claims. Record the signal source and exact timestamp.
3. For severity 3–4, issue the holding line within 15 minutes: aware, verifying, and next-update time.
4. Run the verification checklist: lineage root, independent path, official layer, physical plausibility, state, and timestamp trio.
5. Release the labeled verified picture within 45 minutes during coverage hours. If evidence remains insufficient, explicitly say so and provide the next-check time.
6. Record `holding_line_at` and `verified_update_at`; never reconstruct them later from memory.
7. Keep unresolved claims on a monitoring list with named owner and next-check time.
