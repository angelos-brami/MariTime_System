# R4 — Outage during coverage hours

1. Continue the manual monitoring SOP; tooling loss does not stop the desk.
2. Telegram from an approved phone is the fallback delivery spine.
3. If delivery is affected for more than 30 minutes, send a concise customer status note.
4. Operate in degraded mode: daily brief plus severity 3–4 developments only.
5. Recover services in order: source monitoring, event record, publication, customer portal.
6. Reconcile all manual actions into the database and audit log after recovery.
