# R6 — Key person unavailable

1. Declare degraded mode to the desk and, if material, to customers.
2. Ship the daily brief and severity 3–4 alerts only.
3. Use the written source order, verification checklist, and stored templates; do not rely on memory.
4. Reassign every open event and its next-check time.
5. Suspend lower-severity coverage rather than lowering verification standards.
6. Resume normal coverage only when the four-eyes review can be restored.
