# R2 — Correction

1. Record internal detection time immediately.
2. Classify impact: could an operational decision plausibly have relied on the error?
3. Where staffing permits, the analyst who did not make the error drafts the correction.
4. Human sign-off is mandatory; a model never releases a correction.
5. Issue a clearly labeled correction through every channel that carried the original within 60 minutes of detection.
6. Link the prior and corrected event versions and store channel propagation results.
7. Add the correction to the public accuracy scoreboard and the weekly error council.
8. Record one root cause and one corrective action; do not hide the prior version.
